# **App Name**: HTBase Portal

## Core Features:

- User Authentication: Secure user login and authentication system to manage access to the white-labeled AI trainer.
- Landing Page Customization: Simple landing page with customizable elements (e.g., logo, tagline) to align with each white-label client's brand.
- AI Trainer Integration: Integration with 'Huxleigh Trainer' AI technology for core training functionality.
- Portal Customization: Ability for end-users to customizes different features inside the AI Trainer application based on their brand standards.

## Style Guidelines:

- Primary color: Light turquoise (#7DF9FF) to represent the futuristic theme and highlight important UI elements.
- Background color: Off-white (#F0FFFF), almost imperceptibly turquoise to maintain a clean, futuristic look.
- Accent color: Electric Blue (#7DF9FF), analogous to the primary turquoise but a bit brighter for a stark contrast.
- Font: 'Space Grotesk', sans-serif for a futuristic tech themed font that is easy to read
- Use a set of streamlined icons that reinforce the high-tech style.
- Minimalist design with plenty of white space to achieve a clean, modern feel.
- Use subtle animations to enhance the user experience.
